# 正式知识目录

本目录保存由南京大学官方公开页面形成的结构化摘要，以及少量与新生直接相关、经过审核的外部权威资料。外部资料必须标记为 `maintained`。摘要用于检索，不替代原网页；回答中的精确日期、金额、入口和材料必须遵守条目的受众与时效边界。

## 当前覆盖

- 校园卡挂失、补办、充值与常用服务；
- 统一身份认证账号激活和密码找回；
- 校园网接入与认证；
- 图书馆借阅规则；
- 2026 级本科新生报到日期与选课安排；
- 学费缴纳和学生资助体系；
- 学生住宿业务；
- 成绩单与证明自助服务；
- 校园地图和仙林校区邮政服务；
- 受明确年份限制的体检、医保、注册与请假信息；
- 学生社团官方信息渠道；
- 铁路 12306 学生票优惠资质核验。

体检医保、新生报到材料、宿舍首次入住材料、快递地址等条目目前仍存在年级或校区缺口。系统应利用条目中的“适用边界”给出澄清或有限回答，不能把往年、研究生或单一校区规则泛化。

## 入库要求

- `authority_level` 必须为 `official` 或经审核的 `maintained`；
- `status` 必须为 `active`；
- 必须包含可访问的 `source_url` 和 `retrieved_at`；
- 年级、培养层次、校区和时间范围必须明确；
- 每个条目只陈述其 `source_url` 能直接支持的事实，不拼接无法追溯的来源；
- README、草稿、fixture 和目录概览不得进入线上索引；
- 原网页更新后，应重新核验摘要并更新时效字段。

## 维护流程

1. 从南京大学官方站点确认页面和适用对象。
2. 用自己的语言写结构化摘要，保留必要流程和边界，不复制整页。
3. 运行知识发布 dry-run，检查文档数、Chunk 数、权威度和待生成向量。
4. 在 staging 发布并运行检索/effect evaluation。
5. 查看失败问题的检索来源与引用映射，再决定补知识、调检索还是调整路由。
